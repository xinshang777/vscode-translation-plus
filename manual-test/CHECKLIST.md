# Translation Plus 手工验收清单（v1.9.3）

> 跟着做，25 条，约 10 分钟。每条都对就说明移植到位；哪条不对，把「编号 + 输出面板日志」发出来。

## 0. 准备

| 编号 | 操作 | 预期 |
|---|---|---|
| T0-1 | `Ctrl+Shift+P` → `Developer: Reload Window` | 窗口重载 |
| T0-2 | `Ctrl+Shift+P` → `Output: Focus on Output View` → 下拉选 **Translation Plus** | 出现 `Translation Plus 已启动：引擎=… 目标语言=… 划词=…` |
| T0-3 | `Translation: 自检` | 六行 ✅：引擎连通 / 词典查询 / 发音 / 注释识别 / 增量切片 / 缓存 |
| T0-4 | `Translation: 检测全部引擎` | 输出面板列出 11 个引擎，逐行 ✅/❌（未配 Key 的会显示“未配置…”） |
| T0-5 | 看右下角状态栏 | `🌐 Bing 翻译 → 简体中文`（点一下可切换引擎/TTS） |

## 1. 核心：翻译并替换

| 编号 | 操作 | 预期 |
|---|---|---|
| T1 | 打开 `demo.ts`，选中 `check the file size before uploading it` → `Alt+C` | 弹出**候选列表** + 右侧**替换预览**文档；上下移动预览同步变；回车后变中文 |
| T2 | 再按 `Ctrl+Z` | 一次撤销回英文 |
| T3 | 选中整个函数体（多行）→ `Alt+C` | 全部变中文，缩进不乱 |
| T4 | 光标停在某行（不选区）→ `Ctrl+Shift+Y` | 通知条出译文，带「替换/复制/朗读/打开日志」 |
| T5 | `Alt+点击` 制造两个光标，各在一处英文上 → `Alt+C` | 两处都被替换 |

## 2. 代码安全

| 编号 | 操作 | 预期 |
|---|---|---|
| T6 | 设置 `translation.codeScope = comments`，全选文件 → `Alt+C` | 只有注释变中文；`'/api/upload'`、`'user_id'` 原样 |
| T7 | `codeScope = commentsAndStrings` 重做 | 注释 + `'Upload failed, please retry'` 变中文，路径/ID 不变 |
| T8 | `smartStringFilter = false` 重做 T7 | 连 `'/api/upload'` 也被翻（证明开关生效） |
| T9 | 选中顶部 JSDoc 整块 → `Alt+C` | 逐行翻译，`*` 对齐不破 |

## 3. 中英互译

| 编号 | 操作 | 预期 |
|---|---|---|
| T10 | 选中 `这是一行中文注释，用来测试中英自动互译` → `Alt+C` | 变英文 |

## 4. 卡片 / 词典

| 编号 | 操作 | 预期 |
|---|---|---|
| T11 | 选中一句英文，鼠标**停在选区上** | 卡片：译文 + 引擎 + 「替换/复制/朗读/收藏/全部释义/钉住」 |
| T12 | `hoverMode = word`，悬停单词 `upload` | 卡片：`美 /ˌʌpˈloʊd/` + 释义 + 例句 + 柯林斯 + **文档译文** + 「看原文」 |
| T13 | 点「全部释义」 | 侧栏 Markdown：释义/词形/短语/例句/网络释义/英英/柯林斯 |
| T14 | 点「看原文」 | 卡片切到文档原文，再点回来 |
| T15 | 点「钉住」 | 侧栏打开同一张卡片文档 |

## 5. 文档译文 / 行尾译文

| 编号 | 操作 | 预期 |
|---|---|---|
| T16 | `translation.inlayHints = true`，打开 `demo.ts` | 注释行尾逐个出现 `→ 译文`；悬停 hint 有「复制译文/朗读原文」 |
| T18 | 卡片里点「替换原文」 | 编辑器里该词被替换 |

## 6. 顶栏输入（对应 IDEA 的文本组件翻译）

| 编号 | 操作 | 预期 |
|---|---|---|
| T19 | 在任意输入框里选中文字 → `Ctrl+C` → `Translation: 翻译顶栏输入（剪贴板预填）` | 顶栏输入框已预填剪贴板内容 → 回车 → 顶部候选列表，选第一项译文即复制回剪贴板 |

## 7. 朗读

| 编号 | 操作 | 预期 |
|---|---|---|
| T20 | 选中一句英文 → 点「朗读」 | 1~2 秒内出声；状态栏短暂显示实际引擎（Edge TTS / Google TTS / 系统语音） |
| T21 | 再点一次 | 更快（记住上次成功引擎，不再等 Edge 超时） |

## 8. 增量 / 预览 / 历史 / 生词本

| 编号 | 操作 | 预期 |
|---|---|---|
| T22 | `demo.py` → `Translation: 翻译当前文件中的所有注释`，改 1 条英文再执行一次 | 日志出现 `[incremental] … 缓存命中 N-1 段，实际请求 1 段` |
| T23 | 选中一段 → `Ctrl+Shift+Alt+X` | 左右 diff，点「应用并替换」才写入 |
| T24 | 卡片点「收藏」→ `Translation: 打开生词本`；再 `Translation: 每日一词` | 生词本表格有该词；每日一词随机弹一条完整词条 |
| T25 | `Translation: 打开翻译历史` | 表格列出刚才翻过的条目（时间/引擎） |
